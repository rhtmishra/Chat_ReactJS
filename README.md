💬 Chat App (ReactJS + Chat Engine)
A real-time chat application built with ReactJS and Chat Engine, featuring a sleek UI and smooth user experience. This app allows users to send and receive messages in real-time, styled with CSS and enhanced with Ant Design icons.

🌟 Features
Real-time chat functionality with Chat Engine

User authentication and chat room access

Responsive and modern UI

Clean layout using CSS

Axios for API communication

Ant Design icons for visual enhancement

🛠️ Tech Stack
ReactJS

Chat Engine

Axios

CSS3

@ant-design/icons

📁 Getting Started
Clone the repo
git clone https://github.com/rhtmishra/Chat_ReactJS.git

Install dependencies
npm install

Add your Chat Engine project ID and private key

Start the development server
npm start
